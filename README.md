# ClipOffline

ClipOffline provides desktop tools for downloading video and audio files locally on your computer.

Downloads are performed by a lightweight macOS and Windows plugin that runs entirely on your device, using your own internet connection and storage. The ClipOffline website coordinates download requests, while all media fetching happens locally.

## Repositories

- **clipoffline-releases**  
  Official release builds of the ClipOffline desktop plugin for macOS and Windows.
